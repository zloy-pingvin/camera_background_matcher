# Camera Background Matcher

*[English version](README.md)*

Аддон для Blender 5.2.0. Решает проблему при работе со сканами
(фотограмметрия): десятки/сотни импортированных камер, у каждой нужно
вручную выставить фоновую картинку и clip start — аддон делает это
массово и даёт удобный список камер с превью для навигации.

## Установка

Аддон — это extension Blender. `Edit → Preferences → Add-ons → ⌄`
(справа вверху) `→ Install from Disk…` → выбрать `camera_background_matcher_vX.Y.Z.zip`
— или просто перетащить zip в окно Blender. Панель появится в
`View3D → N-панель → CamTools`.

Если раньше стояла старая версия как legacy-аддон (до 1.4.1), сначала
удалите её (`⌄ → Remove` в её строке): две копии сразу включить нельзя.

## Импорт фонов из папки

После импорта модели из Metashape/RealityCapture/etc. в Blender камеры
приходят с кучей проблем: сломанный clip start, нет фоновых картинок,
всё приходится настраивать вручную по одной.

1. `CamTools → Import from Folder` → выбрать папку с фотографиями со сканирования.
2. Аддон сопоставляет картинки с камерами **по имени** (имя файла = имя камеры).
3. Если сканер добавляет постфиксы к имени файла или камеры (например,
   RealityCapture делает `Camera.png`, из-за чего точное совпадение не
   срабатывает) — включи галочку **Ignore Suffixes** в диалоге импорта.
   Тогда сравнение идёт по части имени до первой точки, с обеих сторон.
4. После импорта у каждой сопоставленной камеры сразу настроен фон —
   ничего вручную выставлять не нужно.
5. Повторный импорт из той же (или другой) папки обновляет фоны у уже
   добавленных камер.

## Массовая настройка camera по всем камерам сцены

В верхнем блоке панели — два ползунка, применяются сразу ко **всем**
камерам сцены (не только к тем, что в списке):

- **Clip Start** — чинит типичный сломанный ближний клиппинг у камер после импорта.
- **Opacity** — прозрачность фоновых картинок, если фон бьёт по глазам или наоборот еле виден.

## Список нужных камер

Сканы дают камеры со всех ракурсов, но конкретно моделировать обычно
удобно по 5–10 ключевым, а остальные нужны только иногда — свериться с
другого угла.

1. Выдели нужные камеры во viewport или в аутлайнере (мультивыделение работает).
2. `Add Selected` — добавляет их в список аддона (список сортируется по
   алфавиту при вставке).
3. `Clear All` — очистить весь список (при необходимости — операция отменяется через Ctrl+Z).
4. Крестик на карточке камеры — убрать одну конкретную камеру из списка.
5. `Remove Every Other` — убирает каждую вторую камеру из **отображаемого**
   списка (полезно быстро проредить и оставить, например, только каждый второй ракурс).

Переименование камер в аутлайнере не ломает список — камеры
отслеживаются по ссылке на объект, а не по имени.

## Сетка превью

- Кнопки **1 / 2 / 3** над списком — сколько колонок превью показывать; ими же регулируется размер картинок.
- Поле поиска — живой фильтр по имени камеры, поиск мгновенный, посимвольный.
- Переключатель **By Name / By Added Order** — сортировка отображения
  (по алфавиту или по порядку добавления); на сам список внутри аддона не влияет.
- Клик по имени камеры сверху карточки или по кнопке **Select Camera**
  снизу — делает камеру активной и переключает вид в Camera View 

## Быстрое переключение камер (хоткей)

`Ctrl + колесо мыши` в 3D-Viewport — листает камеры из списка (учитывает
текущую сортировку). По умолчанию включено.

- Перебиндить или выключить: `Edit → Preferences → Add-ons → Camera Background Matcher` 
- Внизу панели CamTools есть подсказка с текущим биндом (обновляется
  автоматически, если хоткей поменяли).

### В режиме редактирования выделение остаётся на месте

Если меш в режиме редактирования, то при смене камеры (хоткеем или
кликом по карточке) выделенная точка остаётся в том же месте экрана —
вьюпорт сдвигается под неё, как при `Shift + средняя кнопка` в виде из
камеры. Так удобно сверять одну и ту же точку модели по разным фото.

- Опорная точка — активный элемент (последняя кликнутая вершина), а
  если его нет — центр выделения.
- Сама камера не двигается, совмещение с фото не меняется — сдвигается
  только рамка камеры во вьюпорте. Вернуть рамку по центру — `Home`.
- Включается и выключается галочкой **Keep Selection in Place**
  (раздел `SCENE`, по умолчанию включена).
- **Keep Scale** (появляется под ней, по умолчанию включена) ещё и
  приближает / отдаляет вид камеры, как колесо мыши в виде из камеры, —
  область вокруг точки сохраняет размер на экране, даже если следующая
  камера ближе или дальше.

## Скрыть/показать фрустумы камер во вьюпорте

`Hide Camera Icons` внизу панели — прячет треугольники-фрустумы **всех**
камер сцены во вьюпорте, если их визуально слишком много и они мешают
смотреть на модель.

## Выделить камеры в сцене

`Select Cameras in Scene` внизу панели — снимает выделение со всего и
выделяет только камеры из списка аддона (в аутлайнере и вьюпорте).
Удобно, чтобы одним движением перекинуть их все в отдельную коллекцию
(`M` → Move to Collection) или сделать что-то ещё пакетно.
