# Camera Background Matcher

*[English version](README.md)*

Аддон для Blender 4.2 и новее (проверен на 4.2, 4.5, 5.0, 5.2). Решает
проблему при работе со сканами (фотограмметрия): десятки или сотни
импортированных камер, и у каждой нужно вручную выставить фоновое фото и
clip start. Аддон делает это массово и даёт список камер с превью фото,
чтобы переключаться между ракурсами, по которым идёт моделинг.

## Установка

Аддон — это extension Blender. `Edit → Preferences → Add-ons → ⌄`
(справа вверху) `→ Install from Disk…` → выбрать `camera_background_matcher_vX.Y.Z.zip`
— или просто перетащить zip в окно Blender. Панель появится в
`View3D → N-панель → CamTools`; в её заголовке видна установленная версия.

Если раньше стояла старая версия как legacy-аддон (до 1.4.1), сначала
удалите её (`⌄ → Remove` в её строке): две копии сразу включить нельзя.

## Импорт фонов из папки

После импорта модели из Metashape / RealityCapture / etc. камеры
приходят со сломанным clip start и без фоновых картинок, и всё
приходится настраивать вручную, по одной камере.

1. `BACKGROUNDS → Import from Folder` → выбрать папку с фото со сканирования.
2. Фото сопоставляются с камерами **по имени** (имя файла = имя камеры).
3. Если сканер добавляет постфиксы к имени файла или камеры (например,
   RealityCapture называет `Camera.png`, и точное совпадение не
   срабатывает) — включите **Ignore Suffixes** в диалоге импорта: имена
   сравниваются до первой точки, с обеих сторон.
4. У каждой сопоставленной камеры настраивается фон, и она добавляется в
   список камер.
5. Повторный импорт (из той же или другой папки) обновляет фоны у камер,
   которые уже в списке.

## Настройки для всех камер сцены

В разделе `BACKGROUNDS`, применяются ко **всем** камерам, а не только к
тем, что в списке. Значения идут вместе: изменение любого из них
выставляет оба на каждой камере.

- **Clip Start** — чинит ближний клиппинг, который обычно сломан после
  импорта. Тянуть вбок — менять значение (`Shift` — точнее), клик —
  ввести число.
- **Opacity** — прозрачность фоновых фото, если фон бьёт по глазам или
  еле виден.

## Список камер

Сканы дают камеры со всех ракурсов, но моделировать обычно удобно по
5–10 ключевым, а остальные нужны иногда — свериться с другой стороны.

1. Выделите нужные камеры во вьюпорте или в аутлайнере (мультивыделение работает).
2. `Add Selected` — добавляет их в список, по алфавиту.
3. `−½` — убирает каждую вторую камеру из списка **в том виде, как он
   показан** (с текущей сортировкой и поиском) — быстро проредить ракурсы.
4. `Clear All` — очищает список.
5. **×** в конце имени на карточке (появляется при наведении) — убрать из
   списка одну эту камеру.

Любое действие со списком отменяется через `Ctrl+Z`. Сами камеры
остаются в сцене — меняется только список. Переименование камеры в
аутлайнере список не ломает: камеры отслеживаются по объекту, а не по имени.

## Сетка превью

- **Search** — фильтр по имени камеры прямо по мере ввода. `Enter` —
  принять, `Esc` — вернуть прежний текст, × — очистить. В заголовке
  раздела видно, сколько камер подходит.
- **By Added Order / By Name** — только порядок показа; сам список
  хранит порядок добавления.
- **1 / 2 / 3** — число колонок, оно же размер превью.
- На каждой карточке — фото этой камеры (пропорции сетки берутся по
  фото) и имя камеры по нижнему краю. **Клик в любом месте карточки** делает камеру
  активной и переключает вид в Camera View. Карточка активной камеры
  обведена акцентным цветом.

## Переключение камер хоткеем

`Ctrl + колесо мыши` в 3D-вьюпорте — следующая / предыдущая камера
**сетки в том виде, как она показана**: если введён поиск — только по
найденным камерам, в текущей сортировке. По умолчанию включено.

- Внизу панели видны текущие клавиши. Если хоткей выключен, там это
  написано и есть ссылка **Enable** на настройки аддона.
- Перебиндить или выключить: `Edit → Preferences → Add-ons → Camera
  Background Matcher` (или в `Preferences → Keymap`) — новая клавиша
  сохраняется вместе с настройками.

### В режиме редактирования выделение остаётся на месте

Если меш в режиме редактирования, то при смене камеры (хоткеем или
кликом по карточке) выделенная точка остаётся в том же месте экрана —
вид сдвигается под неё, как при `Shift + средняя кнопка` в виде из
камеры. Так удобно сверять одну и ту же точку модели по разным фото.

- Опорная точка — активный элемент (последняя кликнутая вершина), а
  если его нет — центр выделения.
- Сама камера не двигается, совмещение с фото не меняется — сдвигается
  только рамка камеры во вьюпорте. Вернуть рамку по центру — `Home`.
- **Keep Selection in Place** (раздел `SCENE`, по умолчанию включена) —
  включает и выключает это.
- **Keep Scale** (под ней, по умолчанию включена) ещё и приближает /
  отдаляет вид камеры, как колесо мыши в виде из камеры, — область
  вокруг точки сохраняет размер на экране, даже если следующая камера
  ближе или дальше.

## Инструменты сцены

- **Hide Camera Icons** — прячет треугольники-фрустумы **всех** камер
  сцены во вьюпорте, когда их так много, что они мешают смотреть на
  модель. Камеры продолжают работать, фоны тоже. Кнопка становится
  **Show Camera Icons** и возвращает исходные размеры.
- **Select Cameras in Scene** — снимает выделение со всего и выделяет
  только камеры из списка (во вьюпорте и аутлайнере), например чтобы
  одним движением перенести их в коллекцию (`M` → Move to Collection).
